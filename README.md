# 项目编程规范索引

本目录包含完整的项目搭建与编码规范（共 20 个文件），来源于团队企业规范，已适配 WorkBuddy 工作流。

## 使用方式
- **全局核心规则**已写入 `~/.workbuddy/MEMORY.md`，每次会话自动注入
- **详细规范**存放于本目录，按需读取对应文件
