# 技术选型规范

## 1. 基本原则
所有技术栈必须在公司白名单内，禁止小众、废弃、未稳定Beta/Alpha版本。

## 2. 推荐技术清单

| 领域 | 推荐方案 | 禁止/淘汰 |
|------|----------|-----------|
| 前端框架 | Vue3 / React + Vite | - |
| .NET后端 | ASP.NET Core LTS | .NET Framework |
| Java后端 | SpringBoot / SpringCloud | - |
| Go后端 | Gin / Kitex | - |
| Python后端 | FastAPI | Flask |
| 数据库 | MySQL 8.0+ / PostgreSQL 14+ | - |
| 缓存 | Redis | - |
| 消息队列 | RocketMQ / Kafka | - |
| 内部通信 | gRPC / REST | 裸TCP Socket |

## 3. 选型决策文档（强制）
每一次技术选型必须编写 `docs/decisions/ADR-XXX.md`，包含：
- 背景与问题
- 候选方案
- 最终决策
- 优缺点分析
- 备选兜底方案
